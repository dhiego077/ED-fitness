# ED Fitness

Front-end estático em HTML, CSS e JavaScript baseado no layout aprovado da ED Fitness.

## Arquivos

- `index.html` — estrutura e áreas interativas
- `styles.css` — layout responsivo e carrinho lateral
- `script.js` — carrinho com localStorage e checkout via WhatsApp
- `products.json` — catálogo inicial
- `assets/ed-fitness-layout.png` — arte visual do site

## Antes de colocar em produção

Troque o número `5500000000000` pelo WhatsApp real da loja e confirme o endereço do Instagram.

O catálogo JSON é adequado para dados públicos simples, mas GitHub não deve ser usado como banco transacional para clientes, pedidos, senhas, estoque em tempo real ou pagamentos.
